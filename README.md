# S. Sandeep & Associates — fresh React starter

Uses React 18, Vite 6, React Router 6, Tailwind CSS 3 and Lucide icons. Package management is **npm only**.

## Run

```bash
npm install
npm run dev
```

Build with `npm run build`.

This is a frontend-only prototype. Knowledge Bank uses mock content. Forms do not transmit or store data. Admin login is a UI prototype only; connect a secure backend before launch. No client login is included.
